# Site Osman Enghin – Educație Socială 5–8

Acesta este un site static pregătit pentru GitHub Pages.

## Fișiere
- `index.html` – pagina principală
- `style.css` – aspectul site-ului
- `teste/test-initial-clasa-a-V-a.pdf`
- `teste/test-initial-clasa-a-VI-a.pdf`

## Publicare pe GitHub Pages
1. Creează un cont pe GitHub: https://github.com/
2. Creează un repository nou, de exemplu `osman-enghin-educatie-sociala`.
3. În repository, alege **Add file → Upload files**.
4. Încarcă toate fișierele și folderul `teste`.
5. Intră la **Settings → Pages**.
6. La **Build and deployment**, alege **Deploy from a branch**.
7. Alege branch-ul `main` și folderul `/ (root)`, apoi **Save**.
8. După publicare, GitHub îți va afișa adresa site-ului.

## Adăugarea altor PDF-uri
Pune noul PDF în folderul `teste`, apoi adaugă un card în `index.html` cu un link de forma:
`href="teste/numele-fisierului.pdf"`

Nu schimba numele fișierelor existente fără să actualizezi și linkurile din `index.html`.
